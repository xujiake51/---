# 中文论文排版格式规范

本 skill 汇总中文论文的**通用排版与格式要求**，独立于具体赛事，可复用于任意中文论文写作。赛事专属规则（如页数上限、命名、AI 声明等）见项目内《论文编写与修改参考.md》。

## 1. 标题层级

采用三级标题体系：

| 层级 | 内容 | 编号方式 |
|------|------|----------|
| 一级标题 | 论文题目 | 无编号，居中加粗 |
| 二级标题 | 摘要、各主要部分、参考文献、附录 | 正文各节「一、二、三……」 |
| 三级标题 | 各节内部小节 | 「1.1」「1.2」「2.1」…… |

常见二级标题序列：摘要 → 问题重述 → 问题分析 → 模型假设 → 符号说明 → 模型的建立与求解 → 结论 → 参考文献 → 附录。

## 2. 编号规则

- **二级标题**：从「摘要」之后开始编号，序号「一、二、三……」；摘要、参考文献、附录按惯例不编号。
- **三级标题**：格式「上级序号.本级序号」（阿拉伯数字），如 `1.1`、`1.2`、`2.1`；更深一层为 `1.1.1`。
- **图、表**：按所在二级标题（节）的序号编号，格式「节号.序号」，每节重新从 1 计数，如「图5.1」「表2.1」。

## 3. 对齐

- 一级标题（论文题目）与二级标题（各节标题）均**居中**。
- 三级标题**左对齐顶格**，不居中。
- 问题提出等处的分项标签（如「问题一」「问题二」）**加粗**，其正文**不加粗**。

## 4. 页眉页脚

- 全文**不设页眉**。
- 页码位于**页脚中部**，阿拉伯数字连续编号。

## 5. 摘要页

- 摘要（含标题、关键词）置于第一页，作为摘要专用页，**不编号**、无需翻译英文。
- 关键词一行格式：`关键词：` 加粗，词条用分号分隔。

## 6. 表格排版

- 推荐**三线表**（booktabs 宏包）。
- 符号说明等对照表**左对齐**，符号列与含义列之间留**明显间隔**（用 `@{\qquad}` 分隔两列）。
- 表标题（caption）置表格上方，图标题置图下方。

## 7. 参考文献与附录

- 引用他人或公开资料，须按科技论文规范列出参考文献，并在正文引用处标注（`\cite{}`）。
- 附录置于正文之后，含支撑材料文件列表、源程序代码等。

## 8. LaTeX 实现要点

```latex
\documentclass[UTF8,zihao=-4]{ctexart}
\usepackage[top=2.5cm,bottom=2.5cm,left=2.5cm,right=2.5cm]{geometry}
\usepackage{amsmath,amssymb}
\usepackage{graphicx,booktabs,array,multirow,float,caption,listings,xcolor}
\pagestyle{plain}   % 无页眉，页脚居中页码

% 二级标题「一、二、三……」且居中；三级标题「1.1、2.1……」左对齐
\ctexset{
  section    = {format={\zihao{3}\bfseries\centering}, number=\chinese{section}, name={,、}, aftername={}},
  subsection = {format={\zihao{4}\bfseries}, number=\arabic{section}.\arabic{subsection}, aftername={\quad}},
}

% 图、表按节编号（图5.1、表2.1），每节重新从 1 计数
\numberwithin{figure}{section}
\numberwithin{table}{section}
\renewcommand{\thefigure}{\arabic{section}.\arabic{figure}}
\renewcommand{\thetable}{\arabic{section}.\arabic{table}}

% 符号说明表：左对齐，符号列与含义列之间留明显间隔
% \begin{tabular}{p{3.4cm}@{\qquad}p{10.2cm}}
```

## 9. 与赛事规则的关系

- 本 skill 只收**通用、可复用**的排版格式规范。
- 具体赛事的**专属要求**（页数、匿名、命名、AI 声明、支撑材料、评奖后果等）不写入本 skill，统一放在该项目的《论文编写与修改参考.md》中，写作时两者配合使用。

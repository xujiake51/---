# 问题二：出海、海返与穿梭联合运输

## 1. 问题重述

`peopleQ2.csv` 给出 4000 条需求，按方向分三类：**出海** 1600、**海返** 1600、**穿梭** 800（设施→设施，共 56 个 OD 对）。本问与问题一相同，不考虑时间窗与业务优先级、飞机充足，在**最小化总飞机使用时间**基础上尽可能优化座位利用率与油耗，输出 `q2-routes.csv` 与 `q2-assignments.csv`，报告五项指标（同问题一 §8）。

## 2. 与问题一的本质差异

问题一是「机场 → 若干设施 → 机场」的单向运送，人员只下不上，是带容量与燃油约束的单向 VRP（CVRP 变体）。问题二引入海返与穿梭，升级为**带同时取送的车辆路径问题（VRPSPD）**，有三点本质差异：

1. **人员是 OD 对而非"送到即可"**：每名人员由同一架次从起点直送终点，中途不换乘；
2. **载荷剖面非单调**：设施上既有下机（出海、穿梭到达）又有上机（海返、穿梭出发），机上人数先降后升或反复波动，不再是问题一的单调递减；
3. **环游有向**：穿梭 $i\to j$ 要求 $i$ 在 $j$ 之前被访问，故环游方向是决策的一部分，正反两向是不同的候选架次。

## 3. 数据特征与关键洞察

对 `peopleQ2.csv`、`distances.csv` 逐设施统计，得到三点结论，它们是本问建模与求解的基石：

1. **出海与海返总量平衡**（各 1600），且出海即问题一 `peopleQ1` 的子集。
2. **逐设施近乎配对**：设施 $d$ 的净差 $q_d^{\text{out}}-q_d^{\text{ret}}$ 落在 $[-4,+6]$，其中 48/52 设施在 $\pm3$ 以内，即"送去多少人，几乎接回多少人"。
3. **穿梭全部同区块短途**：56 个穿梭 OD 起终点都落在同一区块（F001–F017 / F018–F035 / F036–F052），不跨机场，每 OD 仅 9–19 人。

由 (1)(2)，出海 + 海返可组织为**往返环游**，载荷近似恒定 $\approx\sum_t d_t$，容量上退化为问题一；穿梭是本问真正新增的运力要素，规模小、短途、同区块。又因每 OD 仅 9–19 人 $\le 19$ 座，穿梭无须像出海/海返那样做"满座+尾数"拆分，一条架次即可承载整条穿梭 OD 的全部或部分客流（§4.2）。

## 4. 数学模型

### 4.1 新增符号

| 符号 | 含义 |
|------|------|
| $q_d^{\text{out}},\ q_d^{\text{ret}}$ | 设施 $d$ 的出海、海返总人数 |
| $q^{\text{sh}}_{(i,j)}$ | 穿梭 OD 对 $(i,j)$ 的需求人数 |
| $d_t,\ p_t$ | 架次 $r$ 第 $t$ 站（设施 $s_t$）的出海、海返承载量，各自独立取自该机型尾数份 $\{q^{\text{out}}_{s_t}\bmod c_{m_r}\}$、$\{q^{\text{ret}}_{s_t}\bmod c_{m_r}\}$（可为零） |
| $h_{(i,j)}$ | 架次承载穿梭 OD $(i,j)$ 的人数，$0\le h_{(i,j)}\le q^{\text{sh}}_{(i,j)}$（整数，部分承载） |
| $n_{r,(i,j)}$ | 架次 $r$ 承载 OD 对 $(i,j)$ 的人数 |
| $D_{(i,j)}$ | OD 对 $(i,j)$ 的需求总人数 |
| $\pi_{(i,j)}$ | 主问题 OD 覆盖约束的对偶价（定价用） |
| $k,\ g_r$ | 架次 $r$ 的海上停靠次数、加油停靠次数 |
| $F_r=d_r^{\text{TSP}}\cdot f_{m_r}$ | 架次 $r$ 的燃油消耗量（kg） |
| $E_r=\sum_{\text{seg}\in r}(c_{m_r}-L_{r,\text{seg}})d_{\text{seg}}$ | 架次 $r$ 的空座·距离（座位利用率代理，越小利用率越高） |
| $F_0,\ E_0$ | 油耗、空座·距离的无量纲化基准值 |
| $w_F,\ w_\eta$ | 次指标权重（$w_F+w_\eta=1$） |

其余架次与机型符号（$a_r,\ m_r,\ S_r,\ T_r,\ \lambda_r,\ d_r^{\text{TSP}},\ c_m,\ v_m,\ f_m,\ \bar d_m$ 等）沿用问题一 §5。

### 4.2 需求拆分（满座 + 尾数，出海、海返独立）

出海与海返两个方向**各自独立**套用问题一"满座 + 尾数"拆分（问题一 §6.3.1），不再把二者绑成一对：

- **满座**：设施 $d$ 对机型 $c$ 有 $\lfloor q_d^{\text{out}}/c\rfloor$ 个出海满座 + $\lfloor q_d^{\text{ret}}/c\rfloor$ 个海返满座。因出海≈海返（净差 $|q_d^{\text{out}}-q_d^{\text{ret}}|\le6$），可配成 $\min(\lfloor q_d^{\text{out}}/c\rfloor,\lfloor q_d^{\text{ret}}/c\rfloor)$ 个**往返满座**（同一架去程载 $c$ 人、返程载 $c$ 人，架次数对配对部分减半）+ $\big\lvert\lfloor q_d^{\text{out}}/c\rfloor-\lfloor q_d^{\text{ret}}/c\rfloor\big\rvert$ 个**单向满座**（一程满载、另一程空载）。
- **尾数**：出海尾数份 $\{q_d^{\text{out}}\bmod c\}$ 与海返尾数份 $\{q_d^{\text{ret}}\bmod c\}$ **各自独立、不绑定**——可上不同环游、不同机型；同一条环游内因机型唯一，各站尾数仍同机型。
- **穿梭**：每 OD 仅 $9$–$19$ 人 $\le19$ 座，**不做满座拆分**，作为按需部分承载量 $h_{(i,j)}\in[0,q^{\text{sh}}_{(i,j)}]$ 在环游中顺路承载。

### 4.3 主问题（OD 集合划分，分层 + 加权目标）

以 OD 对为覆盖对象（同一 OD 对人员可互换，按 OD 聚合而非逐人）。目标按**分层 + 加权**两级取优——第一层最小化总飞机使用时间（硬目标），第二层在航时最优解集中对油耗与座位利用率加权取优：

$$
\min \ T=\sum_{r\in\Omega} T_r\lambda_r \tag{1}
$$

$$
\text{s.t.}\quad \sum_{r\in\Omega} n_{r,(i,j)}\lambda_r=D_{(i,j)},\quad\forall(i,j) \tag{2}
$$

$$
\lambda_r\in\mathbb{Z}_+ \tag{3}
$$

设第一层最优航时 $T^*$，第二层在航时最优解集上：

$$
\min\ \Big[w_F\frac{F}{F_0}+w_\eta\frac{E}{E_0}\Big]
=\sum_{r\in\Omega}\Big(w_F\frac{F_r}{F_0}+w_\eta\frac{E_r}{E_0}\Big)\lambda_r
\qquad\text{s.t.}\ \ \sum_{r\in\Omega}T_r\lambda_r=T^*,\ \ (2)(3) \tag{1'}
$$

其中 $F=\sum_r F_r\lambda_r$ 为总油耗、$E=\sum_r E_r\lambda_r$ 为总空座·距离（座位利用率 $\eta$ 的线性代理：$\eta=\sum_r\sum_{\text{seg}}L\,d/\sum_r\sum_{\text{seg}}c_m d$，$E$ 越小 $\eta$ 越高）；$F_0,E_0$ 为无量纲化基准（取第一层解对应值或理论下界），使油耗（kg 量级）与空座·距离（数量级与 $\eta$ 相近）可加。权重 $w_F+w_\eta=1$ 由层次分析法（判断矩阵）确定，并以敏感性分析（$w_F$ 扫 $[0,1]$）验证结论对权重不敏感。

$\Omega$ 为候选架次（列）全集。与问题一的 $y_s$ 主问题（问题一 §6.3.4）不同，此处**不再设拆分变量 $y_s$**：拆分约束内化到列生成中（每条列自含机型与各站接送量），覆盖式主问题因此较问题一**更灵活**——不限定拆分机型，允许跨机型混合覆盖（如某设施由"T3 满座 + T2 尾数"共同覆盖）。

### 4.4 候选架次（列）定义

**满座列**：单设施往返（含 §4.2 的往返满座与单向满座），成本同问题一 §6.3.2。

**尾数合并列** $r$ 由「机型 $m_r$ + 有向顺序 $S_r=(s_1,\dots,s_k)$ + 每站出海尾数 $d_t$、海返尾数 $p_t$（各自独立）+ 穿梭承载 $\{h_{(i,j)}\}$」确定。设第 $t$ 站下机 $d_t$ 人（出海到达）、上机 $p_t$ 人（海返出发），穿梭在对应两站之间上下，则逐弧载荷为

$$
L_0=\sum_{t=1}^{k}d_t,\qquad
L_t=\sum_{u>t} d_u+\sum_{u\le t} p_u+\sum_{i\le t<j} h_{(s_i,s_j)}\quad(t=1,\dots,k) \tag{4}
$$

其中 $h_{(s_i,s_j)}$ 为本架次自 $s_i$ 穿梭至 $s_j$ 的人数（$i<j$，部分承载），其占用 $s_i$ 到 $s_j$ 之间每一弧段上的座位。列 $r$ 须满足：

1. **容量** $\max_{0\le t\le k}L_t\le c_{m_r}$（所有弧段载荷不超过座位数；海返富余的设施靠后访问，先送人空出座位再接人）；
2. **先后** 穿梭 $i$ 在 $j$ 前被访问；
3. **停靠** $k\le5$；
4. **燃油**（问题一 §6.4）。

其 OD 覆盖与成本为

$$
n_{r,(a_r,s_t)}=d_t,\quad n_{r,(s_t,a_r)}=p_t,\quad n_{r,(i,j)}=h_{(i,j)} \tag{5}
$$

$$
T_r=\frac{d_r^{\text{TSP}}}{v_{m_r}}+10k+10g_r \tag{6}
$$

$$
F_r=d_r^{\text{TSP}}\cdot f_{m_r},\qquad
E_r=\sum_{\text{seg}\in r}(c_{m_r}-L_{r,\text{seg}})d_{\text{seg}} \tag{6'}
$$

## 5. 求解算法（列生成：DFS 定价子问题 + 受限主问题 IP）

### 5.1 总体框架（两阶段）

目标分层（§4.3）决定求解分两阶段，每阶段内部都是标准列生成：

1. **阶段一（主目标）**：解式 (1)(2) 的 $\min T$。列生成收敛得 LP 下界，再对受限主问题 CBC 分支定界得整数最优航时 $T^*$；
2. **阶段二（次目标）**：加时间固定约束 $\sum_r T_r\lambda_r=T^*$、目标换为式 (1′)，重跑列生成 + CBC；
3. 每阶段内部：取初始受限主问题（全部满座列 + 每设施单尾数列）→ 解 LP 得对偶价 → **DFS 定价子问题**产出负约化成本列（§5.2）→ 迭代至无负列 → CBC 整数化（§5.4）。

### 5.2 定价子问题（DFS + 约化成本下界剪枝）

尾数拆开（约 $2\times$ 尾数份）与穿梭部分承载（约 $8\times$ 选项）使完整列数达 $10^7$～$10^8$ 量级，**预枚举全部不可行**，故定价不作为"全扫描"，而是一个 DFS 子问题——按当前对偶价生成约化成本为负的列。输入为对偶价 $\pi^{\text{out}}_d,\pi^{\text{ret}}_d,\pi^{\text{sh}}_{(i,j)}$（阶段二再叠加时间固定约束的对偶 $\lambda_0$）：

```
输入：区块设施集合，q_out, q_ret, 穿梭 OD 及 q_sh, 对偶价 π
 1: DFS 枚举 ≤5 设施的访问顺序 S = (s1,…,sk)（逐弧载荷 ≤ c_m 剪枝）:
 2:     for m ∈ {T1,T2,T3}:
 3:         每站 t 独立选取出海尾数 d_t ∈ {0} ∪ {q_out[s_t] mod c_m}
 4:         每站 t 独立选取海返尾数 p_t ∈ {0} ∪ {q_ret[s_t] mod c_m}
 5:         对两端都在 S 内、先后正确的穿梭 OD，取 h ∈ [0, q_sh]:
 6:             rc ← 约化成本 (7)/(7′)；若 rc 的"已定部分 + 剩余下界" ≥ 0 则剪枝
 7:             if rc < -ε: Emit 列 r = (S, m, {d_t}, {p_t}, {h}, T_r, F_r, E_r)
```

关键：列属性含 $T_r,F_r,E_r$ 三项；DFS 用**约化成本下界剪枝**（部分路由的剩余最优增量下界 $\ge0$ 时回退），保证找到全部负约化成本列、又不展开完整 $10^8$ 列空间。

### 5.3 定价（约化成本）与迭代

列 $r$ 的**约化成本**：

$$
\bar c_r=T_r-\sum_{(i,j)}n_{r,(i,j)}\pi_{(i,j)}
=\frac{d_r^{\text{TSP}}}{v_{m_r}}+10k+10g_r-\sum_{t}\big(d_t\pi^{\text{out}}_{s_t}+p_t\pi^{\text{ret}}_{s_t}\big)-\sum_{(i,j)}h_{(i,j)}\pi^{\text{sh}}_{(i,j)} \tag{7}
$$

其中 $\pi^{\text{out}}_d,\pi^{\text{ret}}_d,\pi^{\text{sh}}_{(i,j)}$ 为出海、海返、穿梭约束的对偶价。阶段二起，式 (1′) 的目标项与时间固定约束进入对偶，约化成本改写为

$$
\bar c_r=\Big[w_F\frac{F_r}{F_0}+w_\eta\frac{E_r}{E_0}\Big]+\lambda_0 T_r-\sum_{(i,j)}n_{r,(i,j)}\pi_{(i,j)} \tag{7'}
$$

其中 $\lambda_0$ 为时间固定约束 $\sum_r T_r\lambda_r=T^*$ 的对偶。**终止**：当 DFS 定价子问题返回的最小约化成本 $\ge-\varepsilon$，当前受限主问题已覆盖全部列的 LP 最优，算法收敛。

### 5.4 整数化与燃油后置

列生成得到 LP 最优（下界）。整数解由**受限主问题 CBC 分支定界**求取：此时受限主问题仅含列生成期间物化的几百～几千列，CBC 可精确求解。此为"列生成 + 受限主问题 IP"（**非**完整 branch-and-price——不在分支节点重跑定价），故整数解是启发式上界，最优性 gap 以 $(z_{IP}-z_{LP})/z_{LP}$ 报告（同问题一 §7.6）。

燃油不写入主问题，而在列生成阶段逐列校验/修复（复用问题一 §7.5）：相邻加油点间距离 $\le\bar d_m$；超航程者就近插入 $\mathcal{R}$ 加油点（绕行计入 $d_r^{\text{TSP}}$、停靠 +20 min 占配额），修复后仍不可行则弃列。加油点插入同时改变 $T_r$ 与 $F_r$（绕行增加油耗），在列属性里一并更新。

## 6. 评价指标

五项指标定义同问题一 §8，仅**座位利用率**改为逐弧载荷剖面计算（出海的下降段与海返的上升段都计入）：

$$
\eta=\frac{\sum_{r}\sum_{\text{seg}\in r} L_{r,\text{seg}}\,d_{\text{seg}}}{\sum_{r}\sum_{\text{seg}\in r} c_{m_r}\,d_{\text{seg}}} \tag{8}
$$

# 问题二：出海、海返与穿梭联合运输

## 1. 问题重述

`peopleQ2.csv` 给出 4000 条需求，按方向分三类：**出海** 1600、**海返** 1600、**穿梭** 800（设施→设施，共 56 个 OD 对）。本问与问题一相同，不考虑时间窗与业务优先级、飞机充足，在**最小化总飞机使用时间**基础上尽可能优化座位利用率与油耗，输出 `q2-routes.csv` 与 `q2-assignments.csv`，报告五项指标（同问题一 §8）。

## 2. 与问题一的本质差异

问题一是「机场 → 若干设施 → 机场」的单向运送，人员只下不上，是带容量与燃油约束的单向 VRP（CVRP 变体）。问题二引入海返与穿梭，升级为**带同时取送的车辆路径问题（VRPSPD）**，三点本质差异：

1. **人员是 OD 对而非"送到即可"**：每名人员由同一架次从起点直送终点，中途不换乘；
2. **载荷剖面非单调**：设施上既有下机（出海、穿梭到达）又有上机（海返、穿梭出发），机上人数先降后升或反复波动，不再是问题一的单调递减；
3. **环游有向**：穿梭 $i\to j$ 要求 $i$ 在 $j$ 之前被访问，故环游方向是决策的一部分。

## 3. 数据特征与关键洞察

1. **出海与海返总量平衡**（各 1600），出海即问题一 `peopleQ1` 的子集。
2. **逐设施近乎配对**：设施 $d$ 的净差 $q_d^{\text{out}}-q_d^{\text{ret}}$ 集中在 $[-6,+6]$，绝大多数 $\pm3$，即"送去多少人，几乎接回多少人"。
3. **穿梭全部同区块短途**：56 个穿梭 OD 起终点都落在同一区块（F001–F017 / F018–F035 / F036–F052），不跨机场，每 OD 仅 9–19 人。

由 (1)(2)，出海+海返可组织为**往返环游**，载荷近似恒定 $\approx\sum_t d_t$，容量上退化为问题一；穿梭是本问真正新增的运力要素，规模小、短途、同区块。

## 4. 数学模型

### 4.1 新增符号

| 符号 | 含义 |
|------|------|
| $q_d^{\text{out}},\ q_d^{\text{ret}}$ | 设施 $d$ 的出海、海返总人数 |
| $q^{\text{sh}}_{(i,j)}$ | 穿梭 OD 对 $(i,j)$ 的需求人数 |
| $(d_c,p_c)=(q_d^{\text{out}}\bmod c,\ q_d^{\text{ret}}\bmod c)$ | 设施 $d$ 在机型 $c$ 下的**成对尾数**（出海尾数、海返尾数绑定） |
| $n_{r,(i,j)}$ | 架次 $r$ 承载 OD 对 $(i,j)$ 的人数 |
| $D_{(i,j)}$ | OD 对 $(i,j)$ 的需求总人数 |
| $\pi_{(i,j)}$ | 主问题 OD 覆盖约束的对偶价（定价用） |

### 4.2 需求拆分（成对尾数）

沿用问题一"满座 + 尾数"拆分（Q1 §6.3.1），出海与海返**成对**进行：设施 $d$ 对机型 $c$ 生成成对尾数 $(d_c,p_c)$，含义是"出海剩 $d_c$ 人、海返剩 $p_c$ 人需合并运送"。满座部分为固定成本：$\lfloor q_d^{\text{out}}/c\rfloor$ 个出海满座 + $\lfloor q_d^{\text{ret}}/c\rfloor$ 个海返满座，因出海≈海返可**配对为往返满座**（同一架往返各载 $c$ 人），架次数减半；净残差 $|q_d^{\text{out}}-q_d^{\text{ret}}|\le6$ 极小，基本被尾数吸收（Q1 §6.3.2）。

### 4.3 主问题（OD 集合划分）

以 OD 对为覆盖对象（同一 OD 对人员可互换，按 OD 聚合而非逐人）：

$$
\min \sum_{r\in\Omega} T_r\lambda_r \tag{1}
$$

$$
\text{s.t.}\quad \sum_{r\in\Omega} n_{r,(i,j)}\lambda_r=D_{(i,j)},\quad\forall(i,j) \tag{2}
$$

$$
\lambda_r\in\mathbb{Z}_+ \tag{3}
$$

$\Omega$ 为候选架次（列）全集。与问题一的 $y_s$ 主问题（Q1 §6.3.4）不同，此处**不再设拆分变量 $y_s$**：拆分约束内化到列生成中（枚举只产生"满座 + 一条尾数"的列，等式覆盖自然等价于选机型），主问题更简洁、利于列生成。

### 4.4 候选架次（列）定义

**满座列**：单设施往返，成本同 Q1 §6.3.2。

**尾数合并列** $r$ 由「机型 $m_r$ + 有向顺序 $S_r=(s_1,\dots,s_k)$ + 每站成对尾数 $(d_t,p_t)$ + 穿梭尾数 $\{h_{(i,j)}\}$」确定。设第 $t$ 站下机 $d_t$ 人（出海到达）、上机 $p_t$ 人（海返出发），穿梭在对应两站之间上下，则逐弧载荷为

$$
L_0=\sum_{t=1}^{k}d_t,\qquad
L_t=\sum_{u>t} d_u+\sum_{u\le t} p_u+\sum_{\substack{(i,j)\text{ 穿梭}\\ \text{已上未下}}} h_{ij}\quad(t=1,\dots,k) \tag{4}
$$

列 $r$ 须满足：① **容量** $\max_{0\le t\le k}L_t\le c_{m_r}$（所有弧段载荷不超过座位数，海返富余的设施靠后访问，先送人空出座位再接人）；② **先后** 穿梭 $i$ 在 $j$ 前被访问；③ **停靠** $k\le5$；④ **燃油**（Q1 §6.4）。其 OD 覆盖与成本：

$$
n_{r,(\sigma(d),d)}=d_t,\quad n_{r,(d,\sigma(d))}=p_t,\quad n_{r,(i,j)}=h_{(i,j)} \tag{5}
$$

$$
T_r=\frac{d_r^{\text{TSP}}}{v_{m_r}}+10k+10g_r \tag{6}
$$

## 5. 求解算法（预枚举 + 惰性加列）

列空间 $\Omega$ 规模：满座列 $\le3|\mathcal{F}|$；尾数合并列约 $5.2\times10^6$ 条（三区块合计，探针实测）。**枚举本身秒级完成，但一次性把数百万整数变量塞进集合划分 IP 不可承受**，故采用列生成——预枚举全部列，但只在主问题中物化"被用到的列"（惰性加列）。

### 5.1 总体框架

1. **预枚举**（§5.2）：一次性生成全部候选列 $\Omega$，存为列表；
2. **初始受限主问题**：取可行子集 $\Omega'\subset\Omega$（全部满座列 + 每设施单尾数列）；
3. **求解 LP**：式 (1)(2) 放松 $\lambda_r\ge0$，得对偶价 $\pi_{(i,j)}$；
4. **定价（扫描）**：对 $\Omega$ 逐列计算约化成本，取负者加入 $\Omega'$（§5.3）；
5. **迭代**：回到 3，直至无负约化成本列（LP 收敛）；
6. **整数化**：在 $\Omega'$ 上分支定界求整数解（§5.4）。

### 5.2 预枚举（算法 1）

复用问题一 §7.3 的 DFS，扩展为成对尾数 + 穿梭：

```
输入：区块设施集合，q_out, q_ret, 穿梭 OD 及 q_sh
 1: P ← ∅
 2: for f ∈ 设施, c ∈ {19,16,12}:
 3:     d ← q_out[f] mod c;  p ← q_ret[f] mod c
 4:     if d>0 或 p>0: P ← P ∪ {(f, d, p)}        # 成对尾数份
 5: SH ← ∅
 6: for OD(i,j) ∈ 穿梭, c ∈ {19,16,12}:
 7:     h ← q_sh[i,j] mod c;  if h>0: SH[(i,j)] ∪= {h}
 8: DFS 枚举 P 的子集 S（≤1 份/设施, ≤5 份, Σd≤19 剪枝）:
 9:     for m ∈ {T1,T2,T3} 且 c_m ≥ 最小可达峰值载荷:
10:         for 每个可行访问顺序（逐弧载荷 ≤ c_m）:
11:             for 每个穿梭尾数分配（两端都在 S 内、先后正确、容量可行）:
12:                 Emit 列 r = (S, m, 顺序, 尾数, 穿梭, T_r)
13: Ω 加上全部满座列
```

枚举量级（探针实测）：尾数组合 $3.7\times10^4$～$6.3\times10^4$/区块，完整列 $0.66\times10^6$～$3.0\times10^6$/区块，三区块合计 $\approx5.2\times10^6$ 条，秒级生成。

### 5.3 定价（扫描）与迭代

列 $r$ 的**约化成本**：

$$
\bar c_r=T_r-\sum_{(i,j)}n_{r,(i,j)}\pi_{(i,j)}
=\frac{d_r^{\text{TSP}}}{v_{m_r}}+10k+10g_r-\sum_{t}\big(d_t\pi^{\text{out}}_{s_t}+p_t\pi^{\text{ret}}_{s_t}\big)-\sum_{(i,j)}h_{(i,j)}\pi^{\text{sh}}_{(i,j)} \tag{7}
$$

其中 $\pi^{\text{out}}_d,\pi^{\text{ret}}_d,\pi^{\text{sh}}_{(i,j)}$ 为出海、海返、穿梭约束的对偶价。**定价就是对 $\Omega$ 做一次 $O(|\Omega|)$ 线性扫描**，取 $\bar c_r<-\varepsilon$ 的列加入受限主问题（$\varepsilon$ 为容差，如 $10^{-6}$）。**终止**：当 $\min_{r\in\Omega}\bar c_r\ge-\varepsilon$，当前受限主问题已覆盖全部列的 LP 最优，算法收敛。

### 5.4 整数化与燃油后置

列生成得到 LP 最优（下界）。整数解由受限主问题分支定界求取；因集合划分约束系数为 0-1 且右端为整数，LP 解常接近整，可用"四舍五入 + 贪心修复"得到高质量整数解，gap 以 $z_{IP}$ 与 LP 下界之比报告（同 Q1 §7.6）。

燃油不写入主问题，而在枚举阶段逐列校验/修复（复用 Q1 §7.5）：相邻加油点间距离 $\le\bar d_m$；超航程者就近插入 $\mathcal{R}$ 加油点（绕行计入 $d_r^{\text{TSP}}$、停靠 +20 min 占配额），修复后仍不可行则弃列。

## 6. 评价指标

五项指标定义同问题一 §8，仅**座位利用率**改为逐弧载荷剖面计算（出海的下降段与海返的上升段都计入）：

$$
\eta=\frac{\sum_{r}\sum_{\text{seg}\in r} L_{r,\text{seg}}\,d_{\text{seg}}}{\sum_{r}\sum_{\text{seg}\in r} c_{m_r}\,d_{\text{seg}}} \tag{8}
$$

# 2026 年度"策联杯"数学建模精英联赛 B 题

## 文件存储规范

### 目录结构

```
.
├── 2026年度"策联杯"数学建模精英联赛-B题-附件/   # 官方提供的原始附件（只读）
│   ├── 2026年度"策联杯"数学建模精英联赛-论文格式规范.pdf
│   ├── distances.csv
│   ├── peopleQ1.csv / peopleQ2.csv / peopleQ3.csv
│   ├── q1-assignments.csv / q1-routes.csv
│   ├── q2-assignments.csv / q2-routes.csv
│   └── q3-assignments.csv / q3-routes.csv
├── 2026年度"策联杯"数学建模精英联赛-B题.pdf     # 题目原文
├── code/                                        # 代码（.py / .m / .ipynb）
├── model/                                       # 建模过程文档
├── output/                                      # 程序生成的结果（论文、图、导出数据）
├── paper/                                       # 论文相关素材
└── README.md
```

### 各目录职责

| 目录 | 用途 | 规则 |
|------|------|------|
| `B题-附件/` | 官方原始数据与题目附件 | **只读**，任何情况下不改动、不覆盖原文件 |
| `code/` | 求解代码 | 一个脚本聚焦一件事，命名见下方 |
| `model/` | 建模思路、公式推导、假设 | 按问题拆分，一个文件一个问题 |
| `output/` | 程序运行产物 | 论文正文、图片、导出的表格数据 |
| `paper/` | 论文写作素材 | 参考文献、待整合的文字片段 |

### 命名规范

- **代码**：`功能描述.py`，用一句话能看懂在做什么（如 `热力图.py`、`统计请求.py`）。多个问题共用的逻辑，加问题前缀区分。
- **建模文档**：`第{N}问建模.md`，N 对应题目小问序号。
- **输出数据**：以问题前缀开头，如 `question1_OD矩阵.csv`、`question2_OD矩阵.csv`。
- **输出图片**：`{问题前缀}_{内容}_{图类型}.png`，如 `question1_OD矩阵热力图.png`。
- **原始附件**：保持官方文件名，不做重命名。

### 约定

1. 原始附件目录**只读**：程序读取数据时，用相对路径引用 `B题-附件/` 下的文件，不要复制副本到其他目录。
2. 代码与数据分离：脚本只负责"读入原始数据 → 计算 → 输出"，生成的结果统一写到 `output/`，不在 `code/` 里产生中间文件。
3. 一个问题的求解、建模、输出保持可对应：`code/` 的脚本 → `model/` 的推导 → `output/` 的结果，用相同的问题序号标识。
4. 论文正文最终稿放在 `output/` 下，写作过程中的素材、参考文献放 `paper/`。
